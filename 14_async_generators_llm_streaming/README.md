# Module 14: Async Generators & Google Gemini LLM Streaming

## 📌 Executive Summary
An **Async Generator** (`async def` with `yield`) yields values asynchronously over time. This capability is fundamental for real-time streaming interfaces, such as streaming **Google Gemini LLM token responses** directly to client interfaces as they are generated by the model engine, or streaming rows from **SQLite** without loading whole tables into memory.

> **Note for Users & GitHub Visitors:**  
> If an LLM subscription or API key is not available, the user can use `asyncio.sleep()` to execute code. All scripts include automatic, graceful fallbacks to sleep simulation so the code runs seamlessly in any environment.

## ❓ Exercises & Knowledge Checks

1. **Question**: Why is streaming LLM tokens with an async generator better than waiting for the entire text response?
   - *Answer*: Token streaming dramatically reduces Time-To-First-Token (TTFT) from multiple seconds to a fraction of a second, significantly improving user perceived latency and responsiveness in web applications and chatbots.
